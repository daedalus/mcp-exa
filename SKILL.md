# MCP Exa

MCP server for Exa web search (no API key required).

## When to use this skill

Use this skill when you need to:
- Search the web for information
- Find code examples from GitHub/Stack Overflow
- Get full content from URLs
- Perform advanced web search with filters

## Tools

- `web_search_exa` - Search the web for any topic
- `get_code_context_exa` - Find code examples
- `crawling_exa` - Get full content from a URL
- `web_search_advanced_exa` - Advanced search with filters

## Install

```bash
pip install mcp-exa
```
